===============================================
QUICK FIX: Stop Car Charger in Bluetooth Search
===============================================

ISSUE: Searching "Bluetooth" returns car chargers
CAUSE: Product description mentions "Bluetooth Speakers" in compatibility list
FIX: Use search_tags to define what product IS, not what it works with

===============================================
OPTION 1: Run Complete Fix Script
===============================================
mysql -u your_username -p your_database < FIX_NOW.sql


===============================================
OPTION 2: Manual Quick Fix (Copy-Paste These)
===============================================

-- 1. Add search_tags column (if not exists)
ALTER TABLE `geopos_products` 
ADD COLUMN IF NOT EXISTS `search_tags` TEXT DEFAULT NULL;

-- 2. Fix the specific car charger
UPDATE geopos_products 
SET search_tags = 'car charger, vehicle charger, dual usb, fast charging'
WHERE product_code = 'FA-CAR01';

-- 3. Fix all car chargers
UPDATE geopos_products 
SET search_tags = 'car charger, vehicle charger, dual usb'
WHERE product_name LIKE '%Car Charger%';

-- 4. Tag bluetooth earphones
UPDATE geopos_products 
SET search_tags = 'bluetooth, wireless, earphones, tws'
WHERE product_name LIKE '%Bluetooth%Earphone%';

-- 5. Tag bluetooth speakers
UPDATE geopos_products 
SET search_tags = 'bluetooth, wireless, speaker'
WHERE product_name LIKE '%Bluetooth%Speaker%';

-- 6. Verify the fix
SELECT product_name, search_tags 
FROM geopos_products 
WHERE search_tags LIKE '%bluetooth%';


===============================================
TEST AFTER FIX
===============================================
1. Go to your shop
2. Search "Bluetooth"
3. You should see ONLY:
   - Bluetooth earphones
   - Bluetooth headphones
   - Bluetooth speakers
4. You should NOT see:
   - Car chargers
   - Cables
   - Cases


===============================================
THE GOLDEN RULE
===============================================
Tag what the product IS, not what it works with!

✅ Car Charger → Tag: "car charger, dual usb"
❌ Car Charger → Don't tag: "bluetooth speakers, cameras"

✅ Bluetooth Earphones → Tag: "bluetooth, wireless, earphones"
❌ Bluetooth Earphones → Don't tag: "android, iphone, samsung"
